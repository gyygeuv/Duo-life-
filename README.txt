DUO LIFE v3 — rozszerzona wersja

1. Pobierz ZIP i rozpakuj go.
2. Otwórz folder DuoLife_v3.
3. Otwórz index.html w Chrome. Ważne: plik iskierka.jpg musi pozostać w tym samym folderze co index.html.

Nowości:
- Ilustracja Iskierki na ekranie głównym.
- Delikatna animacja unoszenia smoka.
- Przycisk „Pogłaszcz Iskierkę” z różnymi reakcjami.
- Cztery warianty wyglądu smoka (filtry kolorystyczne).
- Wszystkie funkcje z v2: XP, kryształy, dekoracje, krainy, osiągnięcia, własne misje.

Wersja przeglądarkowa; nie jest APK. Postęp v2 i v3 jest przechowywany oddzielnie.
